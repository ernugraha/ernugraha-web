## Gambaran umum

Fitur utama:

- **Fisika mobil kustom** berbasis raycast: suspensi per roda, model ban dengan lingkaran gesek, mesin dengan kurva torsi, gearbox otomatis/semi/manual, aerodinamika, drift dengan handbrake, serta tabrakan fisik antar mobil.
- **Menu utama** bergaya PTFS: Home, pemilihan lokasi di peta, Options, Tutorial, FAQ, Shop, Credits, Changelog, leaderboard, dan latar panorama.
- **Spawner kendaraan** dengan kategori, kartu mobil, pencarian, serta badge New, Gamepass, Bundle, dan Group Access.
- **Bahan bakar** (stasiun pengisian, biaya cash) dan **nitro** (Developer Product).
- **Efek imersif**: bekas ban drift, asap ban, debu, api knalpot, kamera dinamis, serta sistem suara mesin berlapis RPM.
- **Props** yang terpental saat ditabrak lalu kembali ke tempat semula.
- **Siklus siang-malam** dan fitur Creator's Pack (Freecam dan Custom Time lokal).

{: .box-note}
**Prasyarat.** Roblox Studio, serta pengaturan **Game Settings, Security, Enable Studio Access to API Services** agar data (cash, jarak, opsi, nitro) tersimpan saat uji di Studio. Uji selalu dengan **Play (F5)**, bukan Run, karena Anda membutuhkan karakter untuk duduk di mobil.

## Alur permainan

1. Pemain bergabung. `MenuServer` mematikan `CharacterAutoLoads`, jadi karakter **belum** muncul. `MenuClient` menampilkan menu dengan latar panorama.
2. Pemain menekan **PLAY**, memilih lokasi di peta, lalu **DEPLOY**. Server memanggil `LoadCharacter` dan memindahkan karakter ke lokasi itu.
3. Di dekat **Vehicle Spawner**, pemain menekan **E**, memilih kategori lalu mobil.
4. `SpawnServer` memeriksa: jarak ke spawner, akses (gamepass, bundle, grup), jeda antar spawn, dan area spawn yang kosong. Bila lolos, template **di-clone** ke `Workspace, Vehicles` dan pemain otomatis duduk.
5. `VehicleServer` menyiapkan mobil secara otomatis (lihat bagian berikutnya).
6. Fisika mobil dijalankan oleh **klien pengemudi** (`VehicleClient` memakai `VehicleDynamics`). Mobil kosong disimulasikan server dalam mode rem parkir.
7. Bila pemain mati atau mereset karakter, menu muncul lagi dan pemain memilih lokasi untuk kembali bermain.

### Yang dilakukan otomatis saat sebuah mobil disiapkan

`VehicleServer` mengerjakan hal berikut, jadi Anda **tidak perlu** weld atau anchor manual:

- Melepas roda dan pintu dari bodi, menyimpan posisi roda, lalu menjadikan roda objek visual saja.
- Mengganti anchor semua bagian lain dan me-weld part yang belum tersambung ke `Body`.
- Mengatur massa sesuai `Mass` (kg), gesekan, elastisitas, dan menambahkan pemberat berbentuk pelat agar pusat massa rendah.
- Mengubah setir menjadi `Motor6D`, dan pintu menjadi `HingeConstraint` servo dengan tombol E.
- Membuat efek asap dan api mesin jebol beserta tombol perbaikan.
- Mengatur kepemilikan jaringan mengikuti pengemudi.

## Menambahkan mobil baru

### 1. Persyaratan model

Buat satu **Model** dengan bagian-bagian berikut. Nama di bawah adalah nama bawaan; Anda bebas memakai nama lain asalkan didaftarkan di `VehicleSettings` (langkah 3).

| Bagian | Nama bawaan | Keterangan |
| :----- | :---------- | :--------- |
| Chassis | `Body` | Part terbesar yang menjadi akar mobil. **Depan mobil harus menghadap -Z** (arah LookVector part). |
| Roda | `WheelFL`, `WheelFR`, `WheelRL`, `WheelRR` | Boleh satu Part atau satu Model berisi banyak part. Pusat/pivot roda harus di tengah roda. |
| Kursi pengemudi | (nama bebas) | **Tepat satu** `VehicleSeat` di dalam model. |
| Setir | `SteeringWheel` | Opsional. Berputar mengikuti belokan. |
| Pintu | (didaftarkan di Settings) | Opsional. Part atau Model per pintu. |
| Kursi penumpang | (nama bebas) | Opsional. `Seat` biasa boleh ditambahkan. |

Aturan penting:

- **Roda menyentuh tanah** pada posisi diam. Posisi roda di model dianggap tinggi berkendara normal.
- **Silinder roda** Roblox memiliki sumbu putar di lokal **X**, sesuai pengaturan bawaan. Bila model roda Anda berbeda, ubah `WheelSpinAxis`.
- **Radius roda** dihitung otomatis dari ukuran terbesar part roda (atau isi `Radius` per roda).
- **Skala**: 1 stud sekitar 0,28 meter. Mobil biasa berukuran sekitar 12 x 6 stud.
- Pastikan `Body` (dan bagian bodi lain) memiliki bentuk tabrakan yang baik (`CollisionFidelity` Hull atau Box untuk MeshPart).
- Tidak perlu weld dan tidak perlu mengatur Anchored.

### 2. Letakkan di VehicleTemplates

Pindahkan model ke `ReplicatedStorage, VehicleTemplates`. **Jangan** biarkan di Workspace. Beri nama model yang unik, mis. `Civic`.

### 3. (Opsional) Buat VehicleSettings

Tambahkan sebuah **ModuleScript** bernama `VehicleSettings` **di dalam model**. Cukup tulis nilai yang berbeda dari bawaan; sisanya diambil dari `VehicleConfig`. File contoh lengkap tersedia di `VehicleSettings_Template.lua`.

```lua
return {
	-- nama part (hanya bila berbeda dari bawaan)
	Parts = {
		Body = "Chassis",
		SteeringWheel = "Setir",
		Wheels = {
			FL = { Part = "RodaDepanKiri",    Steer = true,  Drive = false, Brake = true, Handbrake = false },
			FR = { Part = "RodaDepanKanan",   Steer = true,  Drive = false, Brake = true, Handbrake = false },
			RL = { Part = "RodaBelakangKiri", Steer = false, Drive = true,  Brake = true, Handbrake = true },
			RR = { Part = "RodaBelakangKanan", Steer = false, Drive = true, Brake = true, Handbrake = true },
		},
		Doors = {
			{ Part = "PintuKiri",  Hinge = "Front", OpenAngle = 65 },
			{ Part = "PintuKanan", Hinge = "Front", OpenAngle = 65 },
		},
	},

	-- karakter mobil
	Mass = 1250,        -- kg
	MaxSpeed = 200,     -- km/h
	BlowSpeed = 260,    -- km/h, melewati ini terlalu lama membuat mesin jebol
	Engine = { PeakTorque = 220, RedlineRPM = 7200 },
	Tires = { Grip = 1.5 },
	Suspension = { Sag = 0.45, DampingBump = 0.25 },
	Fuel = { Capacity = 48 },

	-- suara dan efek
	Sound = { Preset = "Supercar" },
	Effects = { ExhaustOffset = Vector3.new(1.2, -0.3, 5.8) },
}
```

Cara kerja penggabungan:

- Tabel **berisi nama** (mis. `Engine`, `Tires`) digabung: hanya kunci yang Anda tulis yang diganti.
- Tabel **berbentuk daftar** (mis. `Gears`, `Doors`, `IgnoreFolders`) **diganti seluruhnya**.
- Untuk menghilangkan satu roda, tulis `FL = false` di `Parts.Wheels`.
- Pintu: bila membuka ke arah yang salah, tambahkan `Invert = true`. Bila setir berputar terbalik, set `SteeringWheelDirection = -1`. Bila roda berputar mundur saat maju, set `WheelSpinDirection = -1`.

### 4. Daftarkan di SpawnCatalog

Buka `SpawnCatalog` dan tambahkan satu baris pada `Catalog.Vehicles`:

```lua
{ Id = "Civic", Name = "Civic", Category = "Sedan", Template = "Civic", New = true },
```

| Kolom | Wajib | Keterangan |
| :---- | :---- | :--------- |
| `Id` | Ya | Pengenal unik |
| `Name` | Ya | Nama di kartu |
| `Category` | Ya | Harus ada di daftar `Catalog.Categories` (tambahkan kategori baru di sana bila perlu) |
| `Template` | Ya | Nama model di `VehicleTemplates` |
| `New` | Tidak | `true` menampilkan badge **New!** |
| `Gamepass` | Tidak | ID gamepass khusus mobil ini |
| `Bundle` | Tidak | Kunci bundle (lihat bagian gamepass di bawah) |
| `GroupId`, `MinRank` | Tidak | Hanya untuk anggota grup dengan rank minimal |
| `Image` | Tidak | `rbxassetid://...`. Bila kosong, kartu menampilkan preview 3D otomatis |

### 5. Menjual mobil dengan gamepass atau bundle

Untuk satu mobil, buat gamepass di Creator Hub (Creations, pilih experience, Monetization, Passes, Create a Pass, aktifkan Item for Sale, atur harga), salin Pass ID, lalu isi `Gamepass = ID` pada entri mobil.

Untuk **bundle** (satu gamepass membuka beberapa mobil):

```lua
Catalog.Bundles = {
	F1 = { Name = "F1 Bundle", Gamepass = 123456789, Image = "" },
}

-- di Catalog.Vehicles
{ Id = "F1_A", Name = "F1 Car A", Category = "Sport", Template = "F1_A", Bundle = "F1" },
{ Id = "F1_B", Name = "F1 Car B", Category = "Sport", Template = "F1_B", Bundle = "F1" },
```

Mobil yang punya `Gamepass` sendiri **dan** `Bundle` terbuka bila pemain memiliki salah satunya. Di Shop, setiap bundle tampil sebagai satu kartu berisi daftar mobilnya. ID gamepass yang masih `0` atau kosong berarti mobil **gratis**.

{: .box-warning}
**Pengecekan akses dilakukan di server.** Di Roblox Studio, `MenuConfig.PassStudioFree = true` membuat semua gamepass dianggap dimiliki agar mudah diuji. Ubah ke `false` untuk menguji penguncian dan tombol beli.

### 6. Uji dan setel

Jalankan Play (F5), buka spawner, pilih mobil. Bila ada yang janggal, lihat **View, Output** dan cari pesan berawalan `[OSS]`.

| Gejala | Penyebab umum dan penyelesaian |
| :----- | :----------------------------- |
| Mobil tidak bereaksi sama sekali | Nama part tidak cocok dengan `Parts` (periksa Output), atau tidak ada `VehicleSeat` |
| Roda tidak ikut berputar atau berbelok | Nama roda salah, atau `WheelSpinAxis` tidak sesuai model |
| Mobil menghadap terbalik | Depan bodi bukan -Z. Putar model, atau set `Forward = Vector3.new(0, 0, 1)` |
| Mobil tenggelam atau melayang | Roda tidak menyentuh tanah pada posisi awal; sesuaikan tinggi roda terhadap bodi |
| Terlalu licin | Naikkan `Tires.Grip` |
| Terlalu menempel atau sulit belok | Turunkan `Tires.Grip` atau naikkan `Steering.MaxAngle` |
| Bodi terlalu goyang | Naikkan `Suspension.DampingBump`, turunkan `AccelPitch` dan `BrakePitch` |
| Lambat atau tidak kuat menanjak | Naikkan `Engine.PeakTorque` |
| Drift terlalu mudah berputar | Naikkan `Drift.YawAssist` atau `Drift.HandbrakeGrip` |
| Drift terlalu sulit dimulai | Turunkan `Drift.HandbrakeGrip` |
| Pintu membuka ke arah salah | Tambahkan `Invert = true` pada pintu itu |
| Api knalpot keluar dari tempat yang salah | Atur `Effects.ExhaustOffset` (relatif terhadap Body) |

### 7. Suara berbeda tiap mobil

Semua mobil memakai set suara mesin yang sama, tetapi karakternya bisa dibedakan:

```lua
Sound = { Preset = "MuscleV8" }
-- atau atur sendiri (angka yang Anda tulis menang atas preset):
Sound = { Pitch = 0.8, Bass = 5, Growl = 0.25, Echo = 0.2, Volume = 1.1 }
```

Preset yang tersedia: `Sedan`, `Hybrid`, `MuscleV8`, `Supercar`, `F1`, `Truck`, `Rally`. Untuk mesin yang benar-benar berbeda, siapkan 5 file mesin lain di `AudioAssets.Profiles` lalu pilih dengan `Sound = { Profile = "V8" }`.

### Checklist mobil baru

- [ ] Model memiliki `Body`, 4 roda, tepat satu `VehicleSeat`; depan menghadap -Z
- [ ] Model berada di `ReplicatedStorage, VehicleTemplates`
- [ ] (Opsional) `VehicleSettings` di dalam model
- [ ] Entri ditambahkan di `SpawnCatalog` dengan kategori yang valid
- [ ] (Opsional) Gamepass atau bundle diisi
- [ ] Diuji lewat Play dan disetel (grip, suspensi, torsi, suara)

## Menambahkan map atau lokasi baru

### 1. Syarat dunia untuk fisika mobil

- Permukaan jalan harus **CanCollide = true**. Roda memakai raycast dan **mengabaikan part yang tidak bisa bertabrakan**. Terrain bekerja normal.
- Folder `Vehicles`, `Props`, dan `NPCs` di Workspace **diabaikan** oleh raycast roda (agar mobil tidak naik ke mobil lain atau props). Jangan taruh jalan di folder tersebut.
- Permukaan yang lebih curam dari sekitar 60 derajat dianggap bukan jalan. Lereng landai sampai sedang didukung penuh, termasuk parkir di tanjakan.
- Material permukaan menentukan efek: aspal, beton, dan material keras lain menghasilkan asap ban dan bekas ban; rumput, tanah, pasir, lumpur, dan salju menghasilkan debu.

### 2. Lokasi spawn pemain (Island Selection)

Lokasi di menu adalah **Part di `Workspace, SpawnLocations`**. Tidak perlu mengubah kode.

1. Buat Part (disarankan `Anchored`, `CanCollide` mati, `Transparency` 1), taruh di lokasi yang diinginkan.
2. **Putar** Part agar arah depannya (LookVector) adalah arah hadap pemain saat muncul.
3. Isi atribut (panel Properties, bagian Attributes):

| Atribut | Tipe | Keterangan |
| :------ | :--- | :--------- |
| `DisplayName` | string | Nama di daftar dan peta |
| `Description` | string | Keterangan di bawah peta |
| `Order` | number | Urutan di daftar (kecil di atas) |
| `MapX`, `MapY` | number 0 sampai 1 | Menimpa posisi otomatis di peta |

Titik di peta dihitung otomatis dari posisi Part di dunia memakai `MenuConfig.Map.WorldBounds`. Menambah atau menghapus Part langsung memperbarui menu tanpa restart.

### 3. Gambar peta

1. Buat gambar peta **tampak atas** (bisa tangkapan layar dari atas, atau gambar buatan Anda).
2. Unggah sebagai **Image** di Creator Hub, salin Asset ID-nya.
3. Di `MenuConfig`, bagian `Map`, atur:

```lua
C.Map = {
	Image = "123456789",          -- Asset ID gambar peta
	AspectRatio = 1.6,            -- lebar dibagi tinggi gambar (agar tidak gepeng)
	AutoFromWorld = true,
	WorldBounds = { MinX = -1500, MaxX = 1500, MinZ = -1000, MaxZ = 1000 },
}
```

`WorldBounds` adalah koordinat dunia yang tercakup gambar: **sisi kiri gambar = MinX**, **sisi kanan = MaxX**, **sisi atas = MinZ**, **sisi bawah = MaxZ**. Bila titik di peta tidak pas, sesuaikan angka ini atau isi `MapX` dan `MapY` manual pada Part lokasi.

### 4. Titik kamera panorama menu

Taruh Part di `Workspace, MenuCameras`. Posisi Part adalah tempat kamera berdiri, dan arah depannya adalah arah awal putaran. Kamera berputar 360 derajat pelan, lalu berpindah ke Part berikutnya setelah `Duration` detik (dengan fade hitam). Pilih tempat tinggi dengan pemandangan luas.

Atribut opsional per Part: `Speed` (derajat per detik, negatif untuk arah sebaliknya), `Pitch`, `Fov`, `Duration`. Nilai umum ada di `MenuConfig.MenuCamera`. Bila folder kosong, panorama diambil dari `FallbackCenter`.

### 5. Spawner kendaraan

1. Buat sebuah **Model** di `Workspace, Spawners` (nama bebas, mis. `Garasi Utara`).
2. Di dalamnya, **part pertama** yang dibuat akan menerima tombol **[E] Open Spawner**. Jadikan part ini tiang atau terminal yang mudah dijangkau.
3. Tambahkan part tipis bernama **`SpawnPoint`** (ukuran sekitar 14 x 0,5 x 22, `Anchored`, `CanCollide` **tetap menyala**). Mobil muncul di atasnya dan **menghadap arah depan SpawnPoint**.
4. Pastikan area SpawnPoint kosong dari mobil lain; spawn ditolak bila area terhalang.

Pengaturan jarak, jeda, jumlah mobil per pemain, dan penghapusan mobil terlantar ada di `Catalog.Settings` pada `SpawnCatalog`.

### 6. Pompa bensin

Taruh Part atau Model di `Workspace, FuelStations`; tombol **[E] Refuel** ditambahkan otomatis. Pemain harus memarkir mobil dalam jarak `Fuel.Range` dari pompa dan hampir berhenti. Harga per liter, laju pengisian, dan jarak diatur di `MenuConfig.Fuel`.

### 7. Props (objek yang bisa ditabrak)

Taruh Model atau Part di `Workspace, Props`. Objek diam sampai mobil mendekat, lalu terlepas dan terpental secara fisik. Setelah `ResetTime` (120 detik) objek memudar lalu kembali ke posisi awal. Part dalam satu Model yang belum tersambung akan di-weld otomatis ke part utama. Pengaturan ada di bagian `CONFIG` pada `PropServer`.

### 8. Lingkungan

Siklus siang-malam, kecerahan, atmosfer, dan awan diatur di `EnvironmentCurves` (satu tempat untuk server dan klien). Durasi hari, jam awal, dan kecepatan waktu ada di bagian `Config` modul itu.

### Checklist map baru

- [ ] Jalan: part `CanCollide = true`, tidak berada di folder `Vehicles`, `Props`, atau `NPCs`
- [ ] Part lokasi baru di `SpawnLocations` dengan `DisplayName` dan arah hadap benar
- [ ] Gambar peta dan `WorldBounds` disesuaikan bila wilayah baru berada di luar batas lama
- [ ] Spawner kendaraan lengkap dengan `SpawnPoint` di dekat lokasi spawn
- [ ] Pompa bensin di tempat strategis
- [ ] (Opsional) Titik panorama di `MenuCameras`
- [ ] (Opsional) Props di `Props`

## Sistem pendukung

### Ekonomi dan data pemain

Cash didapat otomatis dari jarak tempuh (`Economy.CashPerKm`) dan dipakai untuk membayar bahan bakar. Data per pemain (cash, total jarak, nitro, opsi, receipt pembelian) disimpan di DataStore `OSS_PlayerData_v1`. Leaderboard memakai OrderedDataStore yang namanya diatur di `Leaderboard.Store`. Total jarak juga tampil sebagai kolom **Distance** di daftar pemain Roblox.

{: .box-warning}
Bila DataStore tidak tersedia saat data dimuat, data pemain **tidak disimpan** pada sesi itu supaya tidak menimpa data asli dengan nilai awal.

### Bahan bakar

Konsumsi dihitung dari daya mesin yang benar-benar dihasilkan, ditambah konsumsi langsam, dengan fuel cut saat lepas gas di RPM tinggi. Konsumsi dan jarak dihitung **server**. Saat tangki kosong, mesin mati dan HUD menampilkan OUT OF FUEL. Opsi **Infinite Fuel** hanya bisa diaktifkan pemilik gamepass `Passes.InfiniteFuel`.

### Nitro

Nitro memakai saldo per pemain (bukan per mobil). Tahan **N** untuk memakai; saldo terpakai `Nitro.UsePerSecond` per detik dan nitro berhenti saat saldo habis. Saldo diisi lewat **Developer Product** yang didaftarkan di `MenuConfig.Nitro.Products` (isi `Id` dan `Amount`). Pembelian diproses dengan receipt yang aman dari pemberian ganda.

### Gamepass dan produk

| Yang dijual | Tempat mengisi ID |
| :---------- | :---------------- |
| Mobil tunggal | `Gamepass` pada entri di `SpawnCatalog` |
| Bundle mobil | `Catalog.Bundles` di `SpawnCatalog` |
| Infinite Fuel | `MenuConfig.Passes.InfiniteFuel.Id` |
| Nitro Fuel (Developer Product) | `MenuConfig.Nitro.Products` |
| Gamepass lain untuk Shop | `MenuConfig.Shop.Extras` |

Mobil bergamepass, bundle, gamepass di `Passes`, dan produk nitro otomatis tampil di **Shop** dengan harga Robux asli dari Roblox.

### Opsi pemain

Daftar opsi ada di `MenuConfig.Options`. Tiap opsi bertipe `bool` (True/False) atau `cycle` (daftar nilai), dan disimpan per akun. Opsi yang saat ini tersedia: Transmission, Speed Unit, Drift Assist, Camera Effects, Effects Quality, Vehicle Volume, Infinite Fuel, Menu Music, dan Music Volume. Untuk membaca opsi dari script klien: `Settings.Get("Kunci")` dengan `Settings` adalah `require` dari `PlayerSettings`.

### Isi halaman menu

Tutorial, FAQ, Credits, dan Changelog diedit langsung sebagai tabel di `MenuConfig` (`Tutorial`, `FAQ`, `Credits`, `Changelog`). Semua teks yang tampil di game ditulis dalam bahasa Inggris.

### Audio

Suara kendaraan memakai file audio yang diunggah ke Creator Hub, lalu Asset ID-nya diisi di `AudioAssets`. Kolom `Id` yang kosong berarti suara itu dimatikan.

| File | Kolom di AudioAssets |
| :--- | :------------------- |
| `engine_1` sampai `engine_5` | `A.Engine` (5 lapisan RPM, jangan ubah `BaseRPM`) |
| `skid` | `A.Skid` |
| `roll` | `A.Roll` |
| `wind` | `A.Wind` |
| `nitro` | `A.Nitro` |
| `oneshots` | `A.OneShots.Id` (benturan, mesin jebol, pintu, letupan knalpot) |

File di atas dibuat oleh `tools/generate_audio.py`. Anda boleh menggantinya dengan rekaman sendiri; cukup sesuaikan `BaseRPM` untuk mesin.

**Musik menu** memakai playlist acak: isi `MenuConfig.MenuMusic.Playlist` dengan `{ Id = ..., Name = "..." }`. Pemutar tidak mengulang lagu yang sama berurutan, dan nyala atau mati serta volumenya diatur dari Options. Tiga lagu contoh dibuat oleh `tools/generate_music.py`.

## Pemecahan masalah

Selalu periksa **View, Output** dan cari pesan berawalan `[OSS]`.

| Gejala | Penyebab dan penyelesaian |
| :----- | :------------------------ |
| Menu tidak muncul saat bergabung | `MenuClient` atau `MenuServer` belum terpasang, atau modul di `OSS` belum lengkap |
| Tombol E spawner tidak muncul | Model spawner tidak berada langsung di `Workspace, Spawners`, atau `SpawnServer` belum berjalan |
| Menu terbuka tetapi mobil tidak muncul | `Template` tidak cocok dengan nama model, model masih di Workspace, atau area SpawnPoint terhalang |
| Pesan "requires a Gamepass" di Studio | Ubah `MenuConfig.PassStudioFree` ke `true` untuk pengujian, atau isi ID dengan benar |
| Cash dan opsi tidak tersimpan | Aktifkan Studio Access to API Services; periksa peringatan DataStore di Output |
| Suara tidak terdengar | Asset ID di `AudioAssets` kosong, audio belum diunggah dengan akun/pemilik yang sama, atau Vehicle Volume bernilai 0% |
| Musik menu tidak berputar | Playlist masih kosong, Menu Music mati, atau Music Volume bernilai rendah |
| Mobil bergetar lalu terpental | Lihat pesan `[OSS] Stabilizer aktif ...` di Output; sertakan pesan itu saat melaporkan |
| Titik lokasi tidak pas di peta | Sesuaikan `WorldBounds` dan `AspectRatio`, atau isi `MapX` dan `MapY` manual |
| Mobil selip di tanjakan | Pastikan `GravityCompensation` bernilai 1 dan torsi mesin cukup |

## Catatan dan batasan

- Fisika mobil dijalankan di **klien pengemudi** demi responsivitas; server memverifikasi hal-hal penting (bahan bakar, jarak, akses, pembelian). Pemain yang memodifikasi klien secara teknis masih bisa memengaruhi fisika mobilnya sendiri dan konsumsi nitro.
- Model yang didukung adalah mobil **empat roda**. Kendaraan dengan jumlah roda lain belum diuji.
- Suara bawaan dibuat dengan sintesis. Rekaman asli menghasilkan kualitas yang jauh lebih baik, dan sistemnya siap menerima file Anda sendiri.
- Data pemain disimpan tanpa penguncian sesi; bila satu akun masuk ke dua server bersamaan, data bisa saling menimpa.

{: .box-note}
**Saran.** Setiap kali menambah konten, lakukan uji singkat berurutan: spawn mobil, berkendara lurus, belok, rem, drift, isi bensin, lalu keluar dan masuk lagi. Pola ini menangkap hampir semua masalah penamaan dan konfigurasi sejak awal.
